## 1. Goal

Add the other items from _Heavy Armor Lizard's Autofire Compendium_ to the module's "Autofire Homebrew Items" pack, automating each one only where that is cheap and reliable. Descriptions are written in our words (go-public spec G2).

## 3. Weapon upgrade facts (CPR v0.92.4)

Verified 2026-10-13.

1. **Upgrade targets.** An `itemUpgrade`'s `system.type` is one of armor, clothing, cyberdeck, cyberware, gear, vehicle, or weapon (`modules/datamodels/item/itemUpgrade-datamodel.js:84-87`). An upgrade cannot be installed into another upgrade (`modules/item/mixins/cpr-container.js:112-118`).
2. **Weapon modifier keys.** `damage`, `rof`, `attackmod`, `magazine`, and `secondaryWeapon` (`modules/system/config.js:521-557`).
3. **`attackmod`** applies to every attack type from the weapon: single shot, Aimed Shot, Autofire, and Suppressive Fire (`modules/item/mixins/cpr-attackable.js:238-260`). Only positive values count in rolls (`modules/item/mixins/cpr-upgradable.js:116`). A situational modifier shows as a toggle in the roll dialog (`modules/rolls/cpr-modifiers.js:184-189`).
4. **`rof`** is display only; nothing reads it mechanically.
5. **Autofire-only bonus.** The only one is the Active Effect key `bonuses.autofire`. It is actor-wide, not tied to a weapon, and applies to Autofire attacks, Suppressive attacks, and Autofire skill checks, because both fire modes switch to the Autofire skill (`cpr-attackable.js:77-81, 133-143`).
6. **Active Effects on upgrades.** An Active Effect on an `itemUpgrade` stays active while the upgrade is merely carried, because the type has no equipped state (likely, from code reading).
7. **Active Effect flags.** Every Active Effect must carry `flags["cyberpunk-red-core"].changes`, or CPR throws when it builds roll modifiers (`cpr-modifiers.js:16-22`).
8. **No modifier grants Autofire.** No key targets `fireModes`, and the Autofire maximum is read from `fireModes.autoFire` directly (`modules/system/register-helpers.js:1230-1251`).
9. **Core items the source builds on.** Smartgun Link is a weapon `itemUpgrade` with `attackmod` +1, size 2, and 500eb (`packs/core/upgrades/itemupgrade.smartgun.link.yaml`). Each Drum Magazine is a weapon `itemUpgrade` per weapon type, with a `magazine` override (45 for the assault rifle) and size 1 (`packs/core/upgrades/itemupgrade.drum.magazine.*.yaml`). CPR's packs have no Pistol Autosear.

## 6. Outstanding questions

1. Can CPR v0.92.4 upgrade modifiers target a single skill such as Autofire (I1, I4)? Answered 2026-10-13: no. `attackmod` covers every attack type from the weapon, and `bonuses.autofire` is an actor-wide Active Effect (sections 3.3 and 3.5).
2. Should I6 and H1 both exist, or is one the alternative to the other? Answered 2026-10-13: the source offers the Optimized Autosear as an alternative to the Pistol Autosear change, for tables that want players to upgrade the autosear first. Only one should be active (decision C6).
3. Author permission and per-item credit (section 2).
4. Is a pack of mostly description-only items useful to the table, or should the first batch wait for automation? Review: a pack of mostly description-only items adds little over the source document itself, which argues for batches that each automate something (decision C1).

## 7. Out of scope

- Enforcing invention checks, costs, or Humanity Loss.
- Items from other sources.
